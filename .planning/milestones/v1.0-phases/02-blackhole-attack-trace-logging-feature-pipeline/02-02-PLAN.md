<objective>
Enhance packet event trace logging with acting node annotations and periodic `NODE_STATUS` telemetry events, and construct the automated Gate 2 verification benchmark asserting quantitative network degradation.

Purpose: Deliver self-contained CSV event traces (DATA-01) containing mobility speed and neighbor counts directly in-band without requiring out-of-band state files (D-06). Establish the quantitative verification gate (Gate 2, ATK-01, D-09, D-10) proving that the Blackhole attack causes a relative PDR drop of $\ge 25\%$ across seeds 42, 43, 44 before any machine learning classifier is trained.
Output: 10-column trace schema with periodic `NODE_STATUS` logger, updated `simulator/metrics.py`, benchmark runner `scripts/verify_gate2_impact.py`, and test suite.
</objective>

<threat_model>
- Gate 2 Bypassing: Proceeding to ML training with an ineffective attack generates a model that learns trivial or uninformative noise. Strict automated enforcement of $\ge 25\%$ relative PDR drop prevents premature model development.
- Trace Schema Desynchronization: If `run_scenario.py` changes the CSV header to 10 columns while `metrics.py` or `feature_extraction/` expects 7 columns, metric computation or feature generation crashes. `TRACE_HEADER` must be synchronized.
- Metric Pollution from Telemetry: In-band `NODE_STATUS` events must not be counted as packet transmissions or drops in `metrics.py`, which would artificially distort PDR and throughput calculations.
</threat_model>

   - Update `log_event`:
     ```python

         self,
         sim_time: float,
         src: int,
         dst: int,
         pkt_id: int,
     ```

   - Implement `_periodic_status_logger(self, interval: float = 1.0) -> Generator[simpy.Event, None, None]`:
     ```python
     while True:
         yield self.env.timeout(interval)
         now = self.env.now
         for nid in sorted(self.nodes.keys()):
             node = self.nodes[nid]
             self.trace_rows.append([
                 f"{now:.6f}",
                 nid,
                 -1,
                 0,
                 "NODE_STATUS",
                 0,
                 "",
                 nid,
                 f"{node.speed:.4f}",
                 len(node.neighbors),
             ])
     ```
   - In `SimulationRunner.initialize_nodes()`: start `self.env.process(self._periodic_status_logger())`.
