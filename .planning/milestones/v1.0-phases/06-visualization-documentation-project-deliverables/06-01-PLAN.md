# Plan 06-01: Publication Plot Portfolio & Plotting Suite Automation

## Objective
Implement the headless, publication-grade visualization library `ml/plots.py` satisfying requirement `RESP-03` and test it with `tests/test_plots.py`. Construct the uncommitted personal orchestrator `.archify/scripts/generate_all_plots.py` that ingests authoritative results from `results/*.csv`, generates all high-resolution 300 DPI figures in `results/plots/`, and outputs a comprehensive visual index in `.archify/PLOTS_CATALOG.md`.

---

<threat_model>
ASVS Level: 1
Threat ID: T-06-01 (Headless Environment GUI Crash)
Description: Matplotlib attempts to initialize an interactive Windows desktop GUI backend (e.g., TkAgg, Qt5Agg) in automated or CI environments, causing runtime process hangs or crashes.
Mitigation: Enforce `import matplotlib; matplotlib.use('Agg')` at the module entry point of `ml/plots.py` and `.archify/scripts/generate_all_plots.py` before any `pyplot` or `seaborn` imports occur.

Threat ID: T-06-02 (Data Provenance & Numerical Inconsistency)
Description: Visualizations plot synthetic or misaligned numbers that do not match the authoritative empirical results in `results/*.csv`, violating non-negotiable evaluation integrity (AGENTS.md Rule 8).
Mitigation: Enforce strict pure CSV ingestion from verified artifacts: `results/closed_loop_metrics.csv`, `results/metrics.csv`, `results/feature_importance.csv`, `results/generalization_metrics.csv`, and `results/isolation_events.csv`. Validate expected columns before rendering; abort with clear error messages if columns or files are missing.

Threat ID: T-06-03 (Accidental Commit of Personal Artifacts)
Description: Personal orchestration scripts or local catalogs in `.archify/` get inadvertently committed to the public Git repository.
Mitigation: Enforce `.gitignore` isolation: `.archify/` is explicitly listed in `.gitignore` (line 31). Verify git status to confirm only `ml/plots.py`, `tests/test_plots.py`, and `results/plots/*.png` are tracked.
</threat_model>

     * `plot_executive_dashboard(df_closed_loop, out_path, dpi=300)`: 4-panel $2 \times 2$ grid showing (a) PDR recovery, (b) Throughput (kbps), (c) Average End-to-End Delay (ms), (d) Routing Overhead ratio across Blackhole 30n, Grayhole p=0.5 30n, Grayhole p=0.7 30n, Grayhole p=0.5 50n.      * `plot_feature_importance(df_importance, out_path, dpi=300)`: Horizontal bar chart comparing top 9 Random Forest features sorted by Permutation Importance (with error bars) alongside Gini Impurity.
     * `plot_generalization_stress(df_gen, out_dir, dpi=300)`: Produces `stress_mobility_vs_recall.png` (mobility speed 1, 5, 10 m/s vs recall & F1) and `stress_droprate_vs_pdr.png` (Grayhole drop probability vs PDR degradation & detection recall).
     * `plot_quarantine_timeline(df_events, out_path, dpi=300)`: Timeline/stem plot visualizing simulation time vs node isolation status, illustrating 2-strike confirmation and 30.0s quarantine decay.
     * `plot_confusion_matrices(df_metrics, out_dir, dpi=300)`: Produces standardized 300 DPI confusion matrix heatmaps (`confusion_matrix_random_forest.png`, `confusion_matrix_decision_tree.png`, `confusion_matrix_svm.png`).
     * `generate_all_figures(results_dir='results', plots_dir='results/plots', dpi=300)`: Master function loading all available results CSVs and generating the complete figure portfolio.
   - Include robust file and column validation: if a required CSV is missing or malformed, raise a descriptive `FileNotFoundError` or `ValueError` rather than failing cryptically.
