# Plan 04-02: Zero-Shot Transfer, Multi-Attack Dataset & Model Training, and Generalization Stress Matrix

## Objective
Benchmark zero-shot transferability of the Phase 3 champion against Grayhole traffic, build a pooled multi-attack dataset (Normal + Blackhole + Grayhole) under strict seed holdout, retrain and tune classifiers under the non-negotiable $\text{FPR} \le 1.0\%$ gate, execute a 3-axis generalization stress matrix (varying node speed, drop probability, and network density), determine the empirical Grayhole detection boundary, and export comprehensive evaluation reports and publication-grade plots.

---

## Tasks

### Task 1: Zero-Shot Transfer Evaluation & Multi-Attack Dataset Pipeline
- **Files Modified:**
  - `ml/generalization.py`:
    - Implement `run_zero_shot_evaluation(model_path, grayhole_test_csv)`:
      - Loads Phase 3 champion (`best_model.joblib`).
      - Evaluates on unseen Seed 44 Grayhole test features.
      - Maps predictions to binary (`Attack` vs `Normal`).
      - Computes Transfer Recall, Precision, and FPR on normal traffic.
  - `ml/dataset.py` & `scripts/build_dataset.py`:
    - Extend `build_dataset.py` to support building a multi-attack dataset:
      - Simulates seeds 42, 43, 44 on both `e3_blackhole_onset_30n.json` and `e4_grayhole_onset_30n.json`.
      - Extends `data/train.csv` (seeds 42+43) and `data/test.csv` (seed 44) to contain all three classes (`Normal`, `Blackhole`, `Grayhole`) while preserving the exact 10-column schema.
      - Updates `data/master.csv` and records row counts, class breakdowns, and SHA-256 digests in `data/dataset_manifest.json`.
- **Verification Command:**
  ```bash
  python -c "import pandas as pd; df = pd.read_csv('data/train.csv'); print(sorted(df['label'].unique()))"
  ```

### Task 2: Multi-Attack Classifier Training, Tuning & FPR-Gated Champion Selection
- **Files Modified:**
  - `ml/train.py`:
    - Update training pipeline to support multi-class labels (`Normal`, `Blackhole`, `Grayhole`) as well as binary attack detection mapping.
    - Preserve uniform `StandardScaler` inside Scikit-learn `Pipeline`.
    - Enforce `class_weight='balanced'` across Random Forest, Decision Tree, and SVM.
    - Run 5-fold Stratified Cross-Validation on combined Seeds 42+43 training data.
    - Save trained candidate models to `ml/models/`.
  - `ml/evaluate.py`:
    - Evaluate candidate models on untouched Seed 44 multi-attack test set.
    - Compute 3-class confusion matrix (3x3) and per-class Precision, Recall, F1.
    - Map predictions to binary (`Normal` vs `Attack`), computing binary Accuracy, Precision, Recall, F1, and FPR on Normal samples.
    - Enforce locked $\text{FPR} \le 1.0\%$ gate.
    - Select champion model (highest Attack F1 subject to $\text{FPR} \le 1.0\%$) and serialize to `ml/models/best_model.joblib`.
    - Update `ml/models/model_metadata.json` with multi-attack performance and gate verification status.
- **Verification Command:**
  ```bash
  python -m ml.train
  python -m ml.evaluate
  ```

### Task 3: Generalization Stress Matrix Benchmark, Reporting & Automated Tests
- **Files Modified:**
  - `scenarios/e4_grayhole_50n.json`: Create 50-node dense scenario config for density stress testing.
  - `scripts/run_generalization_matrix.py`:
    - Implements automated sweep over:
      - Mobility speeds: 1.0 m/s, 5.0 m/s, 10.0 m/s
      - Drop probabilities: 0.3, 0.5, 0.7
      - Network densities: 30 nodes and 50 nodes
    - Uses focused 60s evaluation runs for fast, reproducible execution under 90s total.
    - For each condition, measures network PDR, classification Recall, Precision, and FPR.
    - Determines empirical detection boundary: minimum drop probability where Grayhole drops are statistically separated from natural mobility loss.
    - Exports:
      - `results/generalization_metrics.csv`
      - `results/generalization_report.md`
      - Visualizations: `results/plots/grayhole_detection_boundary.png` and `results/plots/generalization_matrix.png`
  - `tests/test_generalization.py`:
    - Test 1: Zero-shot transfer evaluation returns valid metrics without retraining.
    - Test 2: Multi-attack dataset contains exactly 10 columns, disjoint seed splits, and matching manifest checksums.
    - Test 3: Retrained multi-attack champion satisfies the locked $\text{FPR} \le 1.0\%$ gate.
    - Test 4: Generalization stress matrix script runs cleanly and generates all required reports and plots.
- **Verification Command:**
  ```bash
  python -m pytest tests/test_generalization.py -v
  ```
