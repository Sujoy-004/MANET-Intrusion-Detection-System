       - Accept optional `executor: SimulationExecutorProtocol | None = None` in `__init__`.

       - Register `LiveRunScreen`: import `LiveRunScreen` from `manet.screens.live_run` and add `"live_run": LiveRunScreen` to `ManetApp.SCREENS`.
       - Add action methods:
         - `action_show_live_run() -> None`: switches screen to `"live_run"` (`self.switch_screen("live_run")`).
         - `action_stop_simulation() -> None`: calls `self.supervisor.cancel_simulation()`.
       - Implement safe non-blocking global exit guard per D-04:
         - Override `action_quit()`:
           - Check `if self.supervisor.is_running`:
             - Display a confirmation modal dialog (`QuitConfirmModal`) alerting the operator that an active simulation is running and asking for confirmation to halt and exit.
             - If operator confirms exit:
               - Signal cancellation: `self.supervisor.cancel_simulation()`.

               - When terminal state is reached:
                 - If `INTERRUPTED`: clean shutdown achieved; proceed to `super().action_quit()`.

           - If not running: immediately call `super().action_quit()`.

           - If `ImportError` or `ModuleNotFoundError`:
             - Fail fast with explicit diagnostic error message to stderr explaining that `bootstrap.py` at repository root is required to provide the simulation execution engine.
             - Alternatively initialize `ManetApp(executor=None)` where `ManetApp` renders an explicit warning banner on launch and `start_simulation()` fails fast. A missing executor must NEVER silently produce an app that reports runs as COMPLETED without execution.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI Event Loop -> Background Supervisor | Operator triggers simulation launch, monitor switch, or cancellation from UI screens. |
| OS Process Signals -> Application Lifecycle | Global exit signals (`Ctrl+Q`, window close) intercepted to prevent corrupting in-progress runs. |
| Presentation Layer -> Simulation Backend | Bidirectional package isolation boundary separating `manet/` from `simulator/`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-06 | Denial of Service | `manet/runtime/supervisor.py` | high | mitigate | Strictly enforce single-active-simulation capacity in `WorkloadSupervisor` to prevent concurrent resource contention and thread starvation. |
| T-10-07 | Repudiation / Data Loss | `manet/app.py` | high | mitigate | Intercept global quit (`Ctrl+Q`), display confirmation modal prompt when run is active, and ensure clean cooperative cancellation before exit. |
| T-10-08 | Elevation of Privilege | `manet/commands/registry.py` | medium | mitigate | Enforce that all registered commands (`sim:monitor`, `sim:stop`) map exclusively to predefined `ManetApp` action methods with zero shell or subprocess execution. |
| T-10-SC | Tampering | npm/pip/cargo installs | high | mitigate | Pinned dependencies only (textual 8.2.8, simpy 4.1.2, networkx 3.6.1, scikit-learn 1.8.0, pytest 9.0.2); zero new package installations permitted. |
</threat_model>
