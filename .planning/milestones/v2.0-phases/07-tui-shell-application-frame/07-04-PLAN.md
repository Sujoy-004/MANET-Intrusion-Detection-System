  <name>task 1: session-only settings and high-contrast theme registration</name>
  <files>manet/runtime/settings.py, manet/runtime/theme.py, manet/commands/registry.py, manet/app.py, tests/test_manet_theme.py</files>

  <behavior>
    - manet/runtime/settings.py defines SessionSettings dataclass with in-memory fields: high_contrast (bool), reduced_motion (bool), compact_mode (bool)
    - SessionSettings contains zero persistent disk I/O (no open(), no Path.write_text, no save methods)
    - manet/runtime/theme.py defines SOC_HIGH_CONTRAST with higher contrast background (#000000), surface (#080c10), and bright foreground (#ffffff)
    - ManetApp registers both SOC and SOC_HIGH_CONTRAST during on_mount
    - ManetApp provides action_toggle_high_contrast() which toggles app.theme between "manet-soc" and "manet-soc-high-contrast"
    - ManetApp provides action_toggle_reduced_motion() which toggles animation flags
    - AppCommand registry exposes "theme-toggle" and "motion-toggle" commands
  </behavior>
  <action>
1. Create `manet/runtime/settings.py`:
   - `@dataclass class SessionSettings`:
     - `high_contrast: bool = False`
     - `reduced_motion: bool = False`
     - `compact_density: bool = False`
   - Explicit docstring noting D-09 constraint: strictly session-only, in-memory, no persistence to disk.

2. In `manet/runtime/theme.py`:
   - Define `SOC_HIGH_CONTRAST = Theme(name="manet-soc-high-contrast", dark=True, background="#000000", surface="#05080c", panel="#0d1520", foreground="#ffffff", primary="#00e5ff", secondary="#60a5fa", accent="#4ade80", success="#4ade80", warning="#fbbf24", error="#f87171", variables={...})`.
   - Maintain identical variable keys as `SOC` (`navigation-cyan`, `info-blue`, `healthy-green`, `warning-amber`, `critical-red`, `footer-key-foreground`).

3. In `manet/commands/registry.py`:
   - Append to `_COMMANDS`:
     - `AppCommand(name="theme-toggle", display="Toggle High Contrast", help="Toggle between standard SOC and high-contrast themes", parameters=(), action="action_toggle_high_contrast")`
     - `AppCommand(name="motion-toggle", display="Toggle Reduced Motion", help="Toggle UI motion and animation effects", parameters=(), action="action_toggle_reduced_motion")`

4. In `manet/app.py`:
   - In `on_mount`: register both `SOC` and `SOC_HIGH_CONTRAST`.
   - Instantiate `self.settings = SessionSettings()`.
   - Implement `action_toggle_high_contrast(self) -> None`:
     `self.settings.high_contrast = not self.settings.high_contrast`
     `self.theme = "manet-soc-high-contrast" if self.settings.high_contrast else "manet-soc"`
   - Implement `action_toggle_reduced_motion(self) -> None`:
     `self.settings.reduced_motion = not self.settings.reduced_motion`

5. Create `tests/test_manet_theme.py`:
   - Test `run_test()` toggling theme via `action_toggle_high_contrast()` changes `app.theme` to `"manet-soc-high-contrast"` and back.
   - Verify all semantic color variables exist in both themes.
   - AST test: assert `manet/runtime/settings.py` does not import `os`, `shutil`, `pickle`, `json`, or call any `write_text`/`write_bytes` methods.
  </action>
  <verify>
    <automated>python -m pytest tests/test_manet_theme.py -x</automated>
    <fails_when>non-zero exit or any failed tests</fails_when>
  </verify>
  <done>High contrast theme and session settings are fully implemented, toggleable at runtime, and verified to have zero disk persistence.</done>
  <acceptance_criteria>

    - tests/test_manet_theme.py passes completely
  </acceptance_criteria>
