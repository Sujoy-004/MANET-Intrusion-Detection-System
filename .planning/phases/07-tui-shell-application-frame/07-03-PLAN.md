  <name>task 1: console driver — in-memory history, command resolution, and safe app action dispatch</name>
  <files>manet/commands/console_driver.py, tests/test_manet_console.py</files>
  <read_first>@./07-RESEARCH.md § Pattern 1 & Code Examples; @./07-PATTERNS.md § Console Driver; @manet/commands/registry.py</read_first>
  <behavior>
    - ConsoleDriver parses input strings into command name and arguments
    - ConsoleDriver resolves command against registry.resolve(); on success calls the action method on the app instance
    - On unknown command, returns a clear error message and suggests closest matches from iter_known()
    - On parameter mismatch, returns parameter usage string
    - History buffer stores executed lines up to a fixed bound (100 items); history_prev() and history_next() navigate history
    - ConsoleDriver contains zero imports of os, subprocess, or shutil
  </behavior>
  <action>
Create `manet/commands/console_driver.py`:
- `class ConsoleResult`: dataclass with `success: bool`, `output: str`, `command: AppCommand | None = None`.
- `class ConsoleDriver`:
  - `__init__(self, app: Any, max_history: int = 100)`: initializes an in-memory `collections.deque(maxlen=max_history)` for history and a navigation index.
  - `execute(self, line: str) -> ConsoleResult`: trims line, ignores empty lines, tokenizes with `shlex.split` (or simple whitespace split if quote parsing fails), looks up with `resolve(name, args)`.
  - If resolved: invokes `getattr(self.app, command.action)(**params)` or `getattr(self.app, command.action)()`. Returns `ConsoleResult(True, f"Executed: {command.display}", command)`. Appends line to history.
  - If unresolved: queries `iter_known()`, computes simple string prefix/difflib matches, returns `ConsoleResult(False, f"Unknown command '{name}'. Type 'help' or check command palette.")`.
  - `history_prev() -> str | None` and `history_next() -> str | None` for cycling historical inputs.

Create `tests/test_manet_console.py`:
- Test command execution of known `"workspace"` command.
- Test rejection of shell syntax/unknown commands (e.g. `"ls"`, `"dir"`, `"rm"`, `"cat"`).
- Test parameter validation and error messages.
- Test in-memory history navigation (pushing items, navigating prev/next).
- Assert `ConsoleDriver` has no file system persistence.
  </action>
  <verify>
    <automated>python -m pytest tests/test_manet_console.py -x</automated>
    <fails_when>non-zero exit or any failed tests</fails_when>
  </verify>
  <done>ConsoleDriver successfully resolves and executes app commands, rejects unknown/OS commands, and maintains in-memory history.</done>

    - Rejects invalid commands with structured ConsoleResult(success=False)

    - tests/test_manet_console.py passes completely
  </acceptance_criteria>
