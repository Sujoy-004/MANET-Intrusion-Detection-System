<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input ↦ palette search query | Untrusted text flows into the fuzzy matcher — framework-owned sanitization, never reflected into command execution |
| palette Hit selection ↦ app action | Selected command invokes an app action method — the only sanctioned interpreter of the action string is the callback factory's getattr-on-app dispatch |
| manet/commands ↦ OS | The execution boundary: nothing under manet/commands may construct a process (D-10) |

## STRIDE Threat Register (ASVS Level 1, block on high)

| Threat ID | Category | Component | Disposition | Severity | Mitigation Plan |
|-----------|----------|-----------|-------------|----------|-----------------|
| T-7-01 | Elevation of Privilege | manet/commands/registry.py, palette_provider.py | mitigate | medium | resolve() returns (AppCommand, params) tuples only — no callable construction, no subprocess/shutil/os import anywhere in the package, enforced mechanically by tests/test_manet_import_boundaries.py (task 2); the enforcement rule is never widened. |
| T-7-03 | Tampering | manet/commands/palette_provider.py | mitigate | medium | discover()/search() source candidates exclusively from iter_known(); tests assert the hit-source set equals the registry display set exactly (no extra hits, no hidden commands); no generic executor callbacks (e.g., partial(app.run, raw)) — single getattr-on-app dispatch in one private factory. |
| T-7-02 | Tampering (user trust) | registry initial command set | mitigate | medium | The registry ships only the workspace command (backed by action_show_workspace added in task 1); tests assert hasattr(ManetApp, command.action) for every entry; unimplemented capabilities can never be listed operational (D-20). |
| T-7-04 | Repudiation | registry/provider error paths | mitigate | medium | No exception swallowing: unknown name/arity returns None as a documented value (not a caught-and-hidden exception); no bare except anywhere; unexpected exceptions propagate (test framework would surface them). |
</threat_model>
