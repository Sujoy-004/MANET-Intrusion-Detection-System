3. Background Checksum Worker Pattern:
   - In `on_mount()`, spawn background worker using Textual `@work(thread=True)`:
     ```python
     @work(thread=True)
     def verify_artifacts_worker(self) -> None:
         """Synchronous file hashing running in worker thread."""
         worker = get_current_worker()
         try:
             if worker.is_cancelled:
                 return
             results = self.workspace_adapter.verify_artifact_checksums(self.experiment_dir)
             if worker.is_cancelled:
                 return
             try:
                 self.app.call_from_thread(self._apply_verification_results, results)
             except (RuntimeError, Exception):
                 # Application shutting down or event loop closed; cleanly suppress
                 pass
         except Exception as exc:
             if not worker.is_cancelled:
                 try:
                     self.app.call_from_thread(self._apply_verification_error, str(exc))
                 except (RuntimeError, Exception):
                     pass
     ```
   - In `_apply_verification_results(self, results: dict[str, dict[str, Any]]) -> None`:
     - Guard against stale unmounted screen: `if not self.is_mounted: return`.
     - Updates artifact status badges on the UI thread:
       - `[bold green]VERIFIED ✓[/] (sha256: {hash[:16]}...)`
       - `[bold red]CORRUPTED / TAMPERED ✗[/] (expected: {exp[:16]}..., current: {cur[:16]}...)`
       - `[yellow]MISSING ✗[/]`
       - `[cyan]RECORDED[/] (legacy run)`
   - In `_apply_verification_error(self, error_msg: str) -> None`:
     - Guard against stale unmounted screen: `if not self.is_mounted: return`.
     - Sets badge: `[bold red]VERIFICATION ERROR[/] ({escape(error_msg)})`.
   - In `on_unmount()`:
     - Cancel only screen-scoped workers via `self.workers.cancel_node(self)` (or rely on Textual's automatic DOM-node worker cancellation when the screen unmounts).
     - Never call `self.workers.cancel_all()`, which would cancel unrelated application-level workers (e.g. background workload supervisor or dashboard diagnostics).
