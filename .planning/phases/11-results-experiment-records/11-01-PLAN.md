  <name>Task 1: Tracer slice for atomic manifest finalization and chunked SHA-256 artifact verification</name>
  <files>manet/adapters/workspace.py, tests/test_manet_manifest_artifacts.py</files>
  <action>
Implement the core end-to-end tracer path connecting simulation run finalization, artifact discovery, chunked SHA-256 calculation, atomic manifest persistence, and on-demand integrity verification per D-03 and TUI-20:
1. In `manet/adapters/workspace.py`, create helper function `compute_experiment_artifacts(experiment_dir: Path) -> dict[str, dict[str, Any]]`:
   - Inspects `experiment_dir` for primary generated payload artifacts: `trace.csv`, `isolation_log.json`, and `isolation_log.csv`.
   - For each existing file, computes SHA-256 using 64KB chunking (`while chunk := f.read(65536): hasher.update(chunk)`), tracks total byte size, and counts newline occurrences for row count.
   - Returns mapping: `{filename: {"filename": filename, "relative_path": filename, "absolute_path": str(file_path.resolve()), "size_bytes": size_bytes, "sha256": hasher.hexdigest(), "row_count": row_count}}`.
   - Never hash `manifest.json` into itself to avoid circular hash recursion per D-03.
2. In `update_manifest_status`, when `status` is in `("COMPLETED", "INTERRUPTED")`:
   - Invoke `compute_experiment_artifacts(experiment_dir)` and store results under `manifest_data["artifacts"] = artifacts`.
   - Preserve existing atomic write pattern via temporary file (`tmp_path = experiment_dir / "manifest.json.tmp"`) followed by `os.replace(tmp_path, manifest_path)`.
3. In `manet/adapters/workspace.py`, implement `verify_artifact_checksums(experiment_dir: Path) -> dict[str, dict[str, Any]]`:
   - Reads `manifest.json` from `experiment_dir`.
   - For each recorded artifact in `manifest.get("artifacts", {})`, reads current file on disk if present and calculates current SHA-256.
   - If file does not exist: status is `"MISSING"`.
   - If current hash matches recorded hash: status is `"VERIFIED"`.
   - If current hash does not match: status is `"CORRUPTED"`.
   - Returns mapping: `{filename: {"status": status, "expected_sha256": expected, "current_sha256": current, "size_bytes": size, "row_count": rows}}`.
4. Create test file `tests/test_manet_manifest_artifacts.py` with tracer test `test_tracer_manifest_hash_and_verify` verifying:
   - Creating a temporary experiment directory with simulated `trace.csv`.
   - Calling `update_manifest_status(exp_dir, "COMPLETED", metrics={"pdr": 0.95})`.
   - Verifying `manifest.json` contains `artifacts` with valid 64-character hex `sha256` and matching byte size.
   - Verifying `verify_artifact_checksums(exp_dir)` returns status `"VERIFIED"`.
  </action>
