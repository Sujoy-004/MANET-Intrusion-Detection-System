Implement safe workspace pruning backend functions in `WorkspaceAdapter` in `manet/adapters/workspace.py` per D-04 and TUI-21:
1. Implement `WorkspaceAdapter.preview_experiment_deletion(self, experiment_id: str) -> dict[str, Any]`:
   - Reject symlinked directory candidate:
     - Check `candidate_raw = self.workspace_root / experiment_id`.
     - If `os.path.islink(candidate_raw)`: raise `ValueError(f"Symlinked experiment directory is prohibited: {experiment_id}")`.
   - Resolves candidate directory: `target_dir = candidate_raw.resolve()`.
   - Security validation:
     - Verifies `target_dir.is_relative_to(self.workspace_root.resolve())` and `target_dir != self.workspace_root.resolve()`. If invalid, raises `ValueError(f"Invalid experiment directory traversal attempt: {experiment_id}")`.
     - Verifies `target_dir.is_dir()`. If not found, raises `FileNotFoundError(f"Experiment directory not found: {experiment_id}")`.
   - Recursively enumerates all files and directories in `target_dir` using `os.walk(target_dir, followlinks=False)`:
     - In each iteration `(root, dirs, files)`:
       - Inspect directory entries in `dirs`: for each directory name `d`, check `dir_path = Path(root) / d`; if `os.path.islink(dir_path)`: raise `ValueError(f"Symlinked directory inside experiment directory is prohibited: {dir_path}")`.
       - Inspect file entries in `files`: for each file name `f`, check `file_path = Path(root) / f`; if `os.path.islink(file_path)`: raise `ValueError(f"Symlinked file inside experiment directory is prohibited: {file_path}")`.
       - For legitimate regular files, gather: `relative_path` (relative to `target_dir`), `size_bytes` (from `os.lstat`), `mtime_ns`, and `content_sha256` (computed via 64KB chunking).
   - Computes `total_bytes = sum(f["size_bytes"] for f in files)`.
   - Generates a cryptographic preview fingerprint:
     - Sort files by canonical `relative_path`.
     - Compute SHA-256 over concatenated string of `f"{f['relative_path']}:{f['size_bytes']}:{f['mtime_ns']}:{f['content_sha256']}"`.
     - This guarantees immediate detection of any modification between preview and deletion, including same-size file alterations.
   - Returns preview dict: `{"experiment_id": experiment_id, "path": str(target_dir), "files": files, "total_bytes": total_bytes, "file_count": len(files), "fingerprint": fingerprint}`.
2. Implement `WorkspaceAdapter.delete_experiment_run(self, experiment_id: str, expected_preview: dict[str, Any] | None = None) -> int`:
   - Validates candidate directory and anti-traversal identically to preview.
   - If candidate is a symlink: raise `ValueError`.
   - Pre-deletion cryptographic revalidation:
     - If `expected_preview` is provided, invoke `self.preview_experiment_deletion(experiment_id)`.
     - Compare `fresh_preview["fingerprint"] == expected_preview["fingerprint"]`.
     - If fingerprints mismatch (e.g. file added, deleted, or modified in place, even if same size): raise `RuntimeError("Experiment contents modified since deletion preview was generated. Aborting deletion.")`.
   - Executes removal using `shutil.rmtree(target_dir)`.
   - Robust Windows file lock handling: catches `PermissionError` and raises `RuntimeError(f"Cannot delete experiment run '{experiment_id}': files are locked by another Windows process. Please close any open handles.")`.
   - Catches other `OSError` and raises `RuntimeError` with original error string.
   - Returns total bytes reclaimed.
