    2. In `manet/runtime/supervisor.py`:
       - Define `WorkloadState(Enum)`: `IDLE`, `CONFIGURED`, `RUNNING`, `STOPPING`, `COMPLETED`, `INTERRUPTED`, `FAILED`.
       - Implement `WorkloadSupervisor(executor: SimulationExecutorProtocol | None = None)`.
       - Attributes: `executor`, `state = WorkloadState.IDLE`, `current_request: SimulationLaunchRequest | None = None`, `cancel_token = threading.Event()`, `telemetry = TelemetrySink()`, `worker_handle = None`, `start_monotonic = 0.0`, `last_error: str | None = None`, `stage: str = "IDLE"`, `_lock = threading.Lock()`.
       - Property `is_running -> bool`: returns True if `state in (WorkloadState.RUNNING, WorkloadState.STOPPING)`.
       - Method `start_simulation(request: SimulationLaunchRequest, app: Any) -> None`:
         - Acquire `_lock`. If `self.is_running`: raise `RuntimeError("A simulation workload is already active.")` (enforcing single-simulation capacity invariant).
         - Set `current_request = request`, `cancel_token.clear()`, reset `telemetry` with duration from config, set `state = WorkloadState.RUNNING`, `stage = "INITIALIZING"`, `start_monotonic = time.monotonic()`, `last_error = None`.
         - Atomically update manifest status: `update_manifest_status(request.workspace_dir, "RUNNING")`.
         - Launch worker at app level via `app.run_worker(self._worker_entrypoint, name=f"sim-{request.experiment_id}", group="simulation", thread=True, exit_on_error=False)`.
       - Method `cancel_simulation() -> bool`:
         - Acquire `_lock`. If `state == WorkloadState.RUNNING`: set `state = WorkloadState.STOPPING`, `cancel_token.set()`, call `update_manifest_status(self.current_request.workspace_dir, "STOPPING")`, and return True. If not running, return False (idempotent).
       - Method `_worker_entrypoint() -> None`:
         - Execute `self.executor.execute_simulation(...)`, passing callbacks for stage and progress.
         - Catch any exception as `error_exc`.
         - Apply terminal state race precedence: `FAILED` > `INTERRUPTED` > `COMPLETED`.
         - If `error_exc is not None`: set `state = WorkloadState.FAILED`, `last_error = str(error_exc)`, `stage = "FAILED"`, update manifest with `FAILED` and error details.
         - Elif `cancel_token.is_set()`: set `state = WorkloadState.INTERRUPTED`, `stage = "INTERRUPTED"`, update manifest with `INTERRUPTED` and partial metrics.
         - Else: set `state = WorkloadState.COMPLETED`, `stage = "COMPLETED"`, update manifest with `COMPLETED` and metrics.
