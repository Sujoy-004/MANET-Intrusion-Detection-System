# Plan 05-01: Closed-Loop IDS Response Engine & AODV Route Exclusion Integration

## Objective
Implement the active closed-loop intrusion detection and mitigation response system. Introduce dynamic route isolation and RREP filtering hooks in `simulator/aodv.py`, build the `OnlineIDS` detection and quarantine coordinator in `ml/response.py` utilizing the trained champion classifier (`ml/models/best_model.joblib`), wire closed-loop event processing in `simulator/run_scenario.py`, and validate the entire mitigation subsystem with comprehensive automated tests in `tests/test_closed_loop.py`.

---

<threat_model>
ASVS Level: 1
Threat ID: T-05-01 (RREP Spoofing Bypass)
Description: A malicious node attempts to bypass isolation by forging high-sequence RREPs or intermediate replies across alternating neighbor hops.
Mitigation: Enforce bilateral blacklist checks in `simulator/aodv.py`: `handle_rrep` drops packets if either `prev_hop` OR `rrep.dest` is blacklisted; `handle_rreq` drops if `prev_hop` or `originator` is blacklisted; and `update_route` blocks insertion of blacklisted destinations or next hops.

Threat ID: T-05-02 (Quarantine Flapping & Oscillation)
Description: Rapid cycles of blacklisting and unblocking destabilize the routing table, resulting in constant RREQ flooding storms and packet drops.
Mitigation: Enforce a fixed 30.0s cooling-off quarantine duration (`quarantine_duration = 30.0s`), reset accumulated strikes to 0 upon unblock, and mandate 2 distinct consecutive scan windows ($K=2$) before re-isolation can trigger.

Threat ID: T-05-03 (Endpoint Self-Severing / DoS)
Description: Congestion or radio propagation packet drops cause legitimate CBR traffic endpoints (sources or destinations) to exhibit high drop rates, triggering false-positive isolation and terminating legitimate application flows.
Mitigation: Enforce Decision D-11: `flow_endpoints` (sources and destinations of active flows) are explicitly registered in `OnlineIDS`. If an endpoint node exceeds the detection threshold, it is logged as an alert (`ALERT_ENDPOINT_EXCLUDED`) but is strictly barred from being added to the isolation blacklist.

Threat ID: T-05-04 (Online Distribution Drift)
Description: Feature calculation differences or window size mismatches between online detection and offline training cause model inference failures or invalid probability estimates.
Mitigation: Reconcile window size to $W = 5.0\text{s}$ (matching training data denominator in `data/dataset_manifest.json`), assemble batched Pandas DataFrame with exact column names `SCHEMA_COLUMNS[:9]`, and verify numerical parity against offline extractor via `test_online_ids_feature_parity`.
</threat_model>

     def invalidate_routes_through(self, bad_node: int) -> List[int]:

         Returns list of unreachable destinations."""
         severed: List[int] = []
         for dest, entry in list(self.routing_table.items()):

                 severed.append(dest)
         return severed

   - Implement class `OnlineIDS`:
     - `__init__(self, env: simpy.Environment, aodv_nodes: Dict[int, AODVNode], nodes: Dict[int, NodeState], model_path: Union[str, Path] = "ml/models/best_model.joblib", window_size: float = 5.0, eval_interval: float = 1.0, threshold: float = 0.50, quarantine_duration: float = 30.0, strikes_required: int = 2, flow_endpoints: Optional[Set[int]] = None, isolation_log_path: Optional[Path] = None, scenario_name: str = "default", seed: int = 42)`:
       - Loads model via `joblib.load(model_path)`.
       - Initializes in-memory event deque: `self.event_buffer = deque()`.
       - Initializes state trackers: `self.strikes = defaultdict(int)`, `self.last_strike_time = {}`, `self.quarantined_nodes = {}` (node_id -> expire_time), `self.isolation_events = []`.
       - Stores `self.flow_endpoints = flow_endpoints or set()`.
     - `ingest_event(self, sim_time, src, dst, pkt_id, pkt_type, hop_count, dropped_by, node_id, speed, neighbor_count)`:
       - Appends lightweight record to `self.event_buffer`.
     - `is_blacklisted(self, node_id: int) -> bool`:
       - Returns `True` if `node_id in self.quarantined_nodes` and `self.env.now < self.quarantined_nodes[node_id]`.
     - `_periodic_detection_loop(self) -> Generator[simpy.Event, None, None]`:
       - Yields `self.env.timeout(self.eval_interval)` in a `while True` loop.
       - Prunes events older than `now - self.window_size`.
       - Quarantine maintenance: For any `nid` in `self.quarantined_nodes` where `now >= self.quarantined_nodes[nid]`:
         - Remove from `self.quarantined_nodes`.
         - Reset `self.strikes[nid] = 0`.
         - Log `action="UNBLOCK"`.
       - Identification of active nodes: Nodes with any sent, received, forwarded, or dropped packets within `[now - window_size, now]`.
       - Feature extraction: Compute the 9 non-leaking features matching `extract_features.py`:
         `packet_forward_ratio, packet_drop_ratio, avg_delay, route_request_rate, route_reply_rate, throughput, hop_count, neighbor_count, mobility_speed`.
       - Batched inference: Assemble DataFrame `batch_df = pd.DataFrame(feature_rows, columns=SCHEMA_COLUMNS[:9])`.
         - Call `proba = self.model.predict_proba(batch_df)`.
         - Derive `p_malicious = proba[:, blackhole_idx] + proba[:, grayhole_idx]` (or `1.0 - proba[:, normal_idx]`).
       - Confirmation & quarantine logic ($K=2$, $\tau = 0.50$):
         - For each evaluated node:
           - If `p_malicious >= self.threshold`:
             - If `nid in self.flow_endpoints`:
               - Log `action="ALERT_ENDPOINT_EXCLUDED"` (do not increment strike, do not quarantine).
             - Else:
               - Increment `self.strikes[nid] += 1`.
               - If `self.strikes[nid] >= self.strikes_required` and nid not currently quarantined:
                 - Quarantine node: `self.quarantined_nodes[nid] = now + self.quarantine_duration`.
                 - Purge routes: For every `aodv_node` in `self.aodv_nodes.values()`, call `aodv_node.invalidate_routes_through(nid)`.
                 - Log `action="QUARANTINE"`.
           - Else:
             - Reset `self.strikes[nid] = 0`.
     - `write_isolation_log(self)`: Writes `self.isolation_events` to CSV if `isolation_log_path` provided.
