# Plan 04-01: Grayhole Attack Strategy, Honest Routing Hook, Dynamic Scenario & Time-Aware Feature Extraction

## Objective
Implement the decoupled Grayhole attack strategy (`GrayholeStrategy` in `attacks/grayhole.py`), wire the honest AODV route discovery seam in `simulator/aodv.py`, integrate scenario configuration and runner instantiation in `simulator/run_scenario.py`, generalize feature extraction labeling to dynamic attack types in `feature_extraction/extract_features.py`, and construct the composite test scenario `scenarios/e4_grayhole_onset_30n.json` accompanied by a comprehensive test suite in `tests/test_attacks_grayhole.py`.

---

## Tasks

### Task 1: Grayhole Strategy, AODV Honest Seam & Scenario Runner Integration
- **Files Modified:**
  - `attacks/base.py`: Update `AttackStrategy.get_spoofed_rrep_params` typing to `Optional[Tuple[int, int]]`.
  - `attacks/grayhole.py`: Implement `GrayholeStrategy(AttackStrategy)`:
    - Constructor accepts `drop_prob: float = 0.5`, `target_flows: Optional[List[Tuple[int, int]]] = None`, `target_dests: Optional[List[int]] = None`, `seed: Optional[int] = None`, `rng: Optional[random.Random] = None`.
    - `get_spoofed_rrep_params(self, dest: int, rreq_dest_seq: int) -> Optional[Tuple[int, int]]`: Returns `None` (no spoofing, honest AODV routing).
    - `should_drop_data(self, pkt_src: int, pkt_dst: int, pkt_id: int) -> bool`:
      - If `target_flows` is provided and `(pkt_src, pkt_dst)` is not in `target_flows`, return `False`.
      - If `target_dests` is provided and `pkt_dst` is not in `target_dests`, return `False`.
      - Return `self.rng.random() < self.drop_prob`.
  - `attacks/registry.py`: Register `"grayhole": GrayholeStrategy` in `_REGISTRY`.
  - `simulator/aodv.py`: Update `handle_rreq` so that if `self.attack_behavior.get_spoofed_rrep_params(...)` returns `None`, it does NOT unpack or send a spoofed RREP, but instead proceeds to normal AODV destination check and route forwarding.
  - `simulator/run_scenario.py`:
    - In `__init__`, pass `drop_prob`, `target_flows`, `target_dests`, and `seed=self.seed` to `create_attack_strategy`.
    - If `attack_type.lower() == "grayhole"`, set `self.aodv_nodes[aid].is_grayhole = True`.
    - In `_delayed_attack_activation`, also set `is_grayhole = True` if attack type is Grayhole.
- **Verification Command:**
  ```bash
  python -c "from attacks.registry import create_attack_strategy; s = create_attack_strategy('grayhole', drop_prob=0.5, seed=42); assert s.get_spoofed_rrep_params(1, 1) is None; assert isinstance(s.should_drop_data(0, 1, 100), bool); print('STRATEGY_OK')"
  ```

### Task 2: Dynamic Labeling, Composite Scenario & Comprehensive Grayhole Tests
- **Files Modified:**
  - `feature_extraction/extract_features.py`:
    - Generalize attack label derivation: read `attack_type = scenario_config.get("attack", {}).get("type", "Blackhole")`.
    - If `attack_type.lower() == "grayhole"`, target label is `"Grayhole"`; otherwise `"Blackhole"`.
    - Attacker windows at or after `attack_start_time` receive target label (`Grayhole` or `Blackhole`); pre-onset windows and benign nodes receive `"Normal"`.
    - Verify that feature columns $X$ are completely unchanged.
  - `scenarios/e4_grayhole_onset_30n.json`:
    - Create 30-node composite scenario config: `attack.type = "Grayhole"`, `attack.drop_prob = 0.5`, `attack.start_time = 100.0`, `duration = 300.0`, matching `e3_blackhole_onset_30n.json` topology and flow layout for direct comparability.
  - `tests/test_attacks_grayhole.py`:
    - Test 1: GrayholeStrategy inheritance, registration, and default parameters.
    - Test 2: Honest routing: `get_spoofed_rrep_params` returns `None`, verifying node forwards standard AODV packets.
    - Test 3: Bernoulli drop probability calibration: run 1,000 trials with `drop_prob=0.3`, `0.5`, `0.7`, asserting empirical drop rates fall within binomial 99% confidence bounds.
    - Test 4: Selective filtering: verify non-targeted flows and destinations are never dropped.
    - Test 5: Determinism: two instances instantiated with the same seed generate identical drop sequences.
    - Test 6: Simulation integration: run `e4_grayhole_onset_30n.json` with seed 42, assert simulation completes, PDR is measurably degraded compared to normal baseline, and extracted features contain both `'Normal'` and `'Grayhole'` labels.
- **Verification Command:**
  ```bash
  python -m pytest tests/test_attacks_grayhole.py -v
  ```
